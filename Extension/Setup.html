Count video while you work

Track visible video and background music locally in Daybook.

  1. Move Daybook to Applications. Open Settings → Install Daybook Helper.
  2. Download from GitHub or use the included helper. Daybook verifies and pairs it on your Mac.
  3. Select Brave, Chrome or Edge and click Connect browser. Choose Library/Application Support when asked.
  4. Click Open Extensions, enable Developer mode, then Load unpacked. Select the Daybook-Helper folder shown by the app and approve website access.
  5. Reload media tabs. Existing installations can use Reload in the browser’s Extensions page.

Counting: visible video counts on either display, even without focus. Covered, minimized, offscreen and inactive-tab video does not count as watching. Picture in Picture counts when its window is visible. Audible background YouTube and common music sites count as Music; other hidden video does not. Work, watching and listening can overlap; computer usage counts the union once.

Privacy: the helper reads media progress, sound state and geometry. It passes the top-level domain, playback timing and temporary visibility signals through an encrypted, authenticated local native bridge. Geometry and process identifiers are not saved in activity history. No page text, titles, full URLs, screenshots or audio samples are saved or uploaded. Website access is needed for cross-origin embedded players. Private-window access is off.

Limits: detection starts after setup and tab reload; missing history cannot be reconstructed. Browser throttling, DRM, unusual players, or uncertain visibility can leave gaps. The app needs no screen recording permission. Native Spotify, Apple Music, QuickTime and identifiable local VLC media use a separate opt-in Automation setting. For VLC, keep the video window largest when playback begins; other native video players and unidentifiable VLC video streams need additional adapters. Optional all-app audio on macOS 14.2+ measures sound levels in memory with System Audio Recording permission; only app identity and timing are kept. Known music apps are Music, other sources are Audio. Browsers continue using the helper for domain accuracy.

For a source checkout, build Daybook and use install_bridge.py --browser brave --app /path/to/Daybook.app, load this folder, and pair through the extension options. Reconnect the bridge if Daybook moves.
